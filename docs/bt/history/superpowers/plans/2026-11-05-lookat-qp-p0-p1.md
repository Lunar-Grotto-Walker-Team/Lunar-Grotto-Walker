# QP 注视求解器 P0/P1 修复实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消除 QP 注视求解器的 180° 翻转失效与腕部奇异失效，把近距离低目标的覆盖率从 38% 提到接近 DLS 以上（实测原型 97–100%，全网格 99%）。

**Architecture:** 三处独立改动，全部在 `QpPostureSolver` 内部，不改 `LookatSolver` 接口、不改节点调用点、不改 DLS：① 光轴残差从 `R_z × u` 换成 `u − R_z`（后者只在正对时为零），② 暖启动只缓存"不比目标更背离"的迭代点，③ 把 j5 约束在 `|j5| ≥ 0.60` 的两支之一，每拍按上一拍的支路优先求解一次、失败再解另一支。

**Tech Stack:** C++17、Eigen、qpmad、KDL、tf2、gtest（容器内直跑二进制）。

**Spec:** `docs/superpowers/specs/2026-11-05-lookat-qp-ik-design.md`（§10.2 是本计划的实测依据）

## Global Constraints

- 默认求解器保持 `lookat_solver: dls`；本计划只改 QP 路径，不切换默认值。
- 构建/测试一律在容器内：`docker exec -w /my_ws/l4t/lg_walker_ws self_l4t bash -c "source /my_ws/l4t/.l4t_env.sh && …"`；不用 `colcon test`，直接跑 `build/lgw_bt_planner/<gtest 二进制>`。
- 真机与 mock 绝不能同启；本计划全程不需要真机。
- 所有 `PostureResult` 的语义保持不变：`ok` / `out_of_envelope` / `held_last` / `overrun` / `degenerate`；节点侧零改动（除非 Task 4 的参数声明）。
- 关节限位余量、相机包络、`cond ≤ 50`、`aim ≤ 0.035` 的验收判据一个字都不放宽。
- `max_solve_us`（默认 4000）必须仍然能约束单次 `solve()` 的总耗时，包括两支求解。

## Review Focus

- **目标恰好落在两支的边界上**：同一目标每拍在负支/正支之间来回切换会让 tcp 来回跳（DLS 用档位滞回解决过同类问题）。测试点：Task 3 的 `BranchHysteresis` 与 A/B 的 `worst_step`。
- **原本可解、只因新约束变得不可解的目标**：实测只剩 `|az| ≥ 155°` 的 6/936；必须有测试锁住"其余目标不掉"。测试点：Task 4 的 A/B 覆盖率断言。
- **`held_last` 返回的姿态可能属于另一支**：报告位姿必须与当前支一致，否则节点 HOLD 诊断会误导。测试点：Task 3 的 `WristBranchIsRespected` 对失败结果同样适用。
- **双支求解把单拍耗时翻倍**：4 ms 预算在多目标并发时更容易被打满。测试点：Task 3 的 `TwoBranchSolveStaysInBudget`。
- **缓存跨支残留**：切换支路后若沿用旧支的迭代点，下一拍会把手臂往回拉。测试点：Task 2 的缓存规则 + Task 3 的切换测试。
- **放宽层的姿态落进 Servo 的减速带**：cond 50–70 只减速不停机（硬停是 100），但真机上速度会掉；必须确认放宽层只在边界方位（|az| ≥ 155°）触发。测试点：Task 5 的 `StrictTierKeepsTheGoodPoses` + A/B 的 `mean_cond`。
- **放松层被当成"尽力而为"报告**：50–70 的姿态只能作为 `ok` 输出，不能成为 `best_legal`/`held_last` 的诊断位姿，否则诊断会指向一个会减速的姿态。测试点：Task 5 Step 3 的挑选规则。

```cpp
TEST(QpSolver, WristBranchIsRespected)
{
  // Every reported pose (ok or failure) must sit in the branch the solver
  // declared, otherwise the HOLD diagnostic shows a singular pose.
  QpPostureSolver qp;
  initSolver(qp);
  tf2::Matrix3x3 R;
  tf2::Vector3 t;
  std::tie(R, t) = camInLink6();
  const PostureParams p;
  QpSolverParams q;
  q.j5_branch_min_rad = 0.60;
  qp.set_params(q);
  for (const tf2::Vector3 target :
    {tf2::Vector3(0.75, 0.0, -0.2), tf2::Vector3(0.50, 0.0, -0.37),
     tf2::Vector3(0.35, 0.0, -0.20)})
  {
    const auto r = solveTicks(qp, target, R, t, p, 5);
    EXPECT_GE(std::abs(r.joints[4]), 0.60 - 1e-6) << "status=" << r.status;
  }

TEST(QpSolver, TwoBranchSolveStaysInBudget)
{
  // Two branch runs double the SQP work. The node's solve budget is 4 ms and
  // the control tick is 10 ms, so the mean has to stay well under 1 ms.
  QpPostureSolver qp;
  initSolver(qp);
  tf2::Matrix3x3 R;
  tf2::Vector3 t;
  std::tie(R, t) = camInLink6();
  const PostureParams p;
  double total_ms = 0.0;
  double worst_ms = 0.0;
  const int n = 200;
  for (int i = 0; i < n; ++i) {
    const double az = (i % 37 - 18) * 10.0 * 3.14159265358979323846 / 180.0;
    const tf2::Vector3 target(0.75 * std::cos(az), 0.75 * std::sin(az), -0.2);
    const auto t0 = std::chrono::steady_clock::now();
    const auto r = qp.solve(target, R, t, p);
    (void)r;
    const double ms = std::chrono::duration<double, std::milli>(
      std::chrono::steady_clock::now() - t0).count();
    total_ms += ms;
    worst_ms = std::max(worst_ms, ms);
  }
  EXPECT_LT(total_ms / n, 1.0);
  EXPECT_LT(worst_ms, 8.0);
}

TEST(QpSolver, BranchHysteresis)
{
  // Far target (negative branch) -> close target (positive branch) -> far
  // again. Each step must converge within five calls and stay legal.
  QpPostureSolver qp;
  initSolver(qp);
  tf2::Matrix3x3 R;
  tf2::Vector3 t;
  std::tie(R, t) = camInLink6();

  for (const tf2::Vector3 target :
    {tf2::Vector3(0.75, 0.0, -0.2), tf2::Vector3(0.45, 0.0, -0.37),
     tf2::Vector3(0.75, 0.0, -0.2)})
  {

    ASSERT_TRUE(r.ok) << "status=" << r.status << " aim=" << r.aim_error_rad;
    EXPECT_LE(r.cond, p.cond_max);
  }
}
```

每轮盒约束在原有 6 维计算之后，只改 j5（`k = 4`）：

```cpp
const double lo = kPiperLower[4] + params.joint_margin;
const double hi = kPiperUpper[4] - params.joint_margin;
double j5_lb = std::max(lo - q_last[4], -kTrustRegionRad);
double j5_ub = std::min(hi - q_last[4],  kTrustRegionRad);
if (branch < 0) {
  const double ub_branch = std::min(hi, -qp.j5_branch_min_rad) - q_last[4];
  j5_ub = std::max(j5_lb, std::min(j5_ub, ub_branch));
} else {
  const double lb_branch = std::max(lo, qp.j5_branch_min_rad) - q_last[4];
  j5_lb = std::min(j5_ub, std::max(j5_lb, lb_branch));
}
lb(4) = j5_lb;
ub(4) = j5_ub;
```

要点：**支路约束按信任域放宽**（当前点在另一支时，一次线性化只走 0.2 rad），所以盒永远可行；`max(lb, …)`/`min(ub, …)` 保证 `lb ≤ ub`。

`ok` 与 `best_legal` 的验收条件都追加 `branch_ok`：

```cpp
const bool branch_ok = branch < 0 ?
  q_new[4] <= -qp.j5_branch_min_rad + 1e-9 :
  q_new[4] >=  qp.j5_branch_min_rad - 1e-9;
```

`BranchOutcome` 中同时记录 `aim`，供两支都失败时比较。

Task 2 的缓存条件追加 `branch_ok`：`finite && envelope && cos_aim > 0 && branch_ok`。
这样 `held_last` 报告的姿态也一定满足 `|j5| ≥ j5_branch_min_rad`（否则诊断里会出现
一个奇异带内的姿态）。跨支的行程（最多 1.4 rad）在一次调用的 8 轮 × 0.2 rad 内
走完，所以不缓存中途点不会拖慢切换。

`solve()` 的编排（替换原来的单次循环）：

```cpp
const int preferred = (impl_->have_previous && impl_->previous[4] > qp.j5_branch_min_rad)
  ? +1 : -1;
BranchOutcome a = run_branch(q, preferred);
if (a.ok) { /* 写缓存；return */ }
BranchOutcome b = run_branch(q, -preferred);
if (b.ok) { /* 写缓存；return */ }
```

两支都失败时：优先选有 `best_legal` 的一支（都有时取 `aim` 小的，平局取 `preferred`）；都没有时沿用 `preferred` 的 `held_last`/`degenerate` 语义（与现有代码一致，仍可能抛 `std::runtime_error`）。缓存写入规则：取被选中支的 `cache_ok`/`cache`；被选中支没有合规迭代点则**不改** `impl_->previous`。

`max_solve_us` 的计时改为跨两支共享：把 `t_start` 提到两支之外，每支进入循环前检查剩余预算；预算耗尽时该支直接返回 `overrun` 语义。

```cpp
for (double limit : {params.cond_max, std::max(params.cond_max, qp.cond_max_relaxed)}) {
  BranchOutcome a = run_branch(q, preferred, limit);
  if (a.ok) { /* 缓存；return */ }
  BranchOutcome b = run_branch(q, -preferred, limit);
  if (b.ok) { /* 缓存；return */ }
  /* 记录两支的 best_legal，进入下一层 */
}
```
